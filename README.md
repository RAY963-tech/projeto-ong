# Instituto Mãos que Transformam — Prática 2

Projeto acadêmico de desenvolvimento Front-end com foco em CSS3.

## Estrutura
- `html/index.html` — página inicial
- `html/projetos.html` — projetos
- `html/cadastro.html` — formulário
- `css/style.css` — Design System, Grid, Flexbox, responsividade e componentes
- `js/script.js` — menu, eventos, modal, toast e validação do formulário
- `imagens/` — imagens individuais utilizadas pela interface

## CSS3 aplicado
- Variáveis CSS para cores, tipografia e espaçamento
- Grid de 12 colunas no layout principal
- Flexbox em alinhamentos e componentes
- Breakpoints: 1200px, 992px, 768px, 576px e 400px
- Estados `hover`, `focus`, `active` e `disabled`
- Validação visual dos campos do formulário
- Menu responsivo com submenu
- Modal e toast para feedback visual
